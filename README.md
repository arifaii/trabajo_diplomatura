# ☕ Miga & Coffee

Landing Page responsive desarrollada como **Single Page** para una cafetería ficticia, utilizando únicamente **HTML5 y CSS3** con metodología **Mobile First**.

## 🚀 Tecnologías

- HTML5
- CSS3
- Flexbox
- Google Fonts
- Font Awesome

## ✨ Características

- Diseño responsive
- Single Page
- Navegación por secciones
- Hero principal
- Tarjetas de productos
- Galería de imágenes
- Formulario de contacto
- Footer con redes sociales

## 📁 Estructura

```
miga-and-coffee/
│
├── assets/
├── css/
│   └── styles.css
├── index.html
└── README.md
```

## 📱 Responsive

El proyecto fue desarrollado con **Mobile First**, utilizando los siguientes breakpoints:

- Tablet: `768px`
- Desktop: `1024px`
